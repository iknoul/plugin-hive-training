# ShipHub

## Setup

Requirements: Node.js 22+

Install all dependencies:

```bash
npm run install:all
```

## Run

Start the API and frontend:

```bash
npm run dev
```

## Tests

```bash
cd shiphub-api
node unit-test.js
```

## API Documentation

See [docs/api.md](shiphub-api/docs/api.md) for API endpoints, request parameters, and responses.s
